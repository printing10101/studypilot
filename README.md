# StudyPilot · 本地 AI 助教

WorkBuddy 架构（模式 / 技能 / 专家团 / 连接器 / 项目空间）× DeepPilot 式三层记忆的本地学习助手。

## 架构

```
┌─ frontend (React+Vite, :5173) ─────────────────────────┐
│ 今日学习 学习对话(Ask/Plan/Craft) 教材书库 知识库        │
│ 测验 闪卡 学习计划 记忆图谱(缺陷诊断+依赖图谱)           │
└──────────────────────┬─────────────────────────────────┘
                       │ /api
┌──────────────────────▼──────────── backend (FastAPI, :8178) ─┐
│ 专家团路由 qa/examiner/grader/planner（Ask 支持苏格拉底引导模式）│
│ 技能 quiz.generate / quiz.grade / wrong.redo / wrong.variants │
│     / note.summarize / plan.study / review.generate …         │
│ 三层记忆 L1镜像 → L2摘要(LLM压缩) → L3长期档案(错题/薄弱点)     │
│ RAG: pymupdf解析 → 分块 → BGE向量 × BM25词法 双通道RRF融合      │
│     (带引用；可选 cross-encoder 精排 RERANK_MODEL)             │
│ 教材书库: 预置书目 + 官方免费教材直链获取 + 自有教材上传          │
│          + 挂载到课程空间参与 RAG（library.py）                │
│ 连接器: 本地上传 + MCP 客户端骨架(connectors.py)               │
│ 存储: SQLite(data/studypilot.db，线程本地连接) + uploads/      │
└──────────────────────┬───────────────────────────────────────┘
                       │ OpenAI 兼容 /v1
            llama-server / Ollama / LM Studio / 云端API
```

## 启动

### 方式一：桌面应用（推荐）

- 桌面双击 **StudyPilot** 快捷方式（已创建，带应用图标、无控制台黑窗）
- 或运行 `studypilot/启动桌面版.bat`（带控制台，便于看日志）
- 桌面端数据/日志：`backend/desktop.log`；关窗即退出，重复双击不会起第二个服务（自动复用 8178 的已有服务）

单进程桌面应用：pywebview（Edge WebView2）原生窗口 + 内嵌 FastAPI 服务 + 托管前端构建产物。
前端改动后需先 `cd frontend && pnpm build` 再打开桌面端。图标源文件 `backend/app.ico`。

### 方式二：开发模式（前后端热更新）

```bash
# 1) 模型后端（.env 中 LLM_BASE_URL / LLM_API_KEY / LLM_MODEL 可配，
#    兼容 llama-server / Ollama / LM Studio / 云端 API）
cd backend && uv sync
uv run uvicorn app.main:app --host 127.0.0.1 --port 8178
# 2) 前端
cd frontend && pnpm install && pnpm dev   # http://localhost:5173
```

## 使用闭环

1. 新建课程空间（如"清华普通物理"）
2. **今日学习**页（默认落地页）：到期复习、到期闪卡、当日计划任务、错题数一屏聚合，
   磁贴点击直达对应页面；一键「生成到期复习题」开始间隔复习
3. 教材书库页：一键获取官方免费开放教材、上传自有正版教材 PDF，或粘贴网址剪藏在线讲义入库
4. 知识库页上传讲义 PDF / 老师的 PPTX 课件（含讲者备注）/ 图片（离线 OCR 提取文字）/
   zip 压缩包（自动展开导入包内全部可识别文件）→ 分块向量化；
   书库教材/课件「挂载到空间」后同样参与检索（老版 .ppt 请先另存为 .pptx）
5. 学习对话：Ask 答疑（带引用，公式走 KaTeX 渲染；正则宽松路由"出题/计划"等意图）
   → 开启「💡 引导模式」后切换为苏格拉底式教学（先确认卡点、逐层提示，不直接给答案）
   → 对每条回答反馈「👍 懂了 / ✗ 没听懂」，负反馈自动提取知识点并削弱掌握度
6. 测验页生成题目 → 答题 → 交卷判分 → 错题写入 L3 记忆、错题本与知识点掌握度；
   也支持「模拟考试」（按掌握度采样组卷、限时作答、按知识点出小结）
7. 错题本：整卷/勾选「重做」原题，或「变式训练」——对错题生成同知识点、
   换数字/换情境/换问法的变式题，检验真理解而非背答案
8. 测验页「费曼讲解检验」：用自己的话讲一个概念，判卷专家评估准确/遗漏/误解并更新掌握度
9. 闪卡页从讲义生成问答卡，按 **FSRS 记忆算法**四档刷卡（忘了/困难/良好/轻松，按钮预告下次间隔）：
   目标记住率 90%，间隔随个人评分历史自适应；新卡先经分钟级学习步进，答对毕业进入天级间隔
10. 学习计划页：目标一键拆成分阶段任务清单（自动带截止日期，可手动改期），完成打卡；
    掌握度历史按天画趋势线
11. 记忆图谱页查看缺陷诊断、依赖图谱（力导向 SVG：节点按掌握状态着色、箭头指向后继、
    点节点看前置/后继并可一键"出 3 题练它"）、到期复习与趋势；一键「生成薄弱点复习题」
    （FSRS 间隔复习：按每人的评分历史自适应排期，遗忘快的知识点更快重现）
12. 学习报告 / 错题本 / 学习计划均可一键导出 Markdown 存档

## 学涯规划 · 培养方案库 · 课程表 · 目标导向计划

左侧「学涯规划」页：**选学校 → 看培养方案 → 传课程表 → 按目标生成学习计划**。

- **培养方案库**（`backend/app/syllabus/`）：
  - `schools.json` 收录全国 **113 所 985/211 高校**（39 所 985 + 74 所 211，含分校口径与军医大学），
    每校带城市/地区/层次/优势专业标签，支持简称模糊匹配（示例大学、华科、哈工大、中科大…）；
  - `programs/*.json` 收录 **21 个主流专业**的通用培养方案框架（计算机/软工/AI/大数据/电子信息/通信/
    机械/电气/自动化/土木/材料/化工/数学/物理/经济/金融/法学/临床医学/工商管理/英语/汉语言文学），
    依据教育部教学质量国家标准与多校公开培养方案整理，含学分结构、核心课先修链、八学期路径、
    保研/考研/就业/竞赛/出国出口与时间窗；
  - **官方培养方案层**（`overrides/*.json`）：结构化字段只录官方文件明确的事实
    （学校/专业/学分结构/来源 URL/版本），界面可跳转官方来源；
    高校官方全文 PDF/TXT 不再随仓库分发，可按 overrides 中的来源 URL 自行获取后放入本地 `handbooks/`；
  - **本校校准**：上传本校培养手册 PDF/截图（离线 OCR）或粘贴文本，LLM 只抽取手册中明确出现的事实
    存 `syllabus_custom` 表；合并优先级 **用户导入 > 官方层 > 通用模板**（`coverage` 字段明示数据构成）。
  - 接口：`GET /api/syllabus/schools|majors|program|official|fulltext`、`POST /api/syllabus/import`（文本/文件）。
- **课程表**：上传教务系统截图（RapidOCR）/ Excel(.xlsx) / CSV / 粘贴文本 → 规则解析
  （周X·第X节·周次·教室·教师），解析过少时 LLM 兜底；结果先预览、可逐格修正再保存，
  周视图网格 + 编辑列表双视图，按学期管理。
  接口：`GET/PUT/DELETE /api/schedule`、`POST /api/schedule/import`（文本/文件）。
- **目标导向学习计划**：目标（保研/考研/就业/竞赛/出国/期末/毕业）× 培养方案先修链 × 本学期课表
  × 跨空间薄弱点 × 升学政策库，生成分阶段可打卡计划（任务带验收标准与关联课程）；
  支持导出 Markdown、一键**同步到课程空间**的学习计划（plan_tasks）参与每日打卡闭环。
  接口：`POST /api/planner/generate`、`GET /api/planner[/{id}]`、`POST /api/planner/{id}/toggle|push`、
  `DELETE /api/planner/{id}`。
- 「个人档案」页的学校/专业输入已联动培养方案库（datalist 候选），成长手册与学涯规划共用同一份档案。
- 扩展：新专业仿照现有 JSON 在 `programs/` 增加文件；新院校信息改 `schools.json`（或直接在应用内
  导入该校培养手册），均无需改代码。

## 智能闭环：反馈 → 薄弱点 → 复习

- **反馈采集**：`POST /api/spaces/{sid}/feedback`，消息级 👍/👎 + "没听懂" + 文字补充；
  负反馈由模型提取涉及的知识点（最多 3 个），写入掌握度模型与 L3 弱点档案。
- **掌握度模型**：`mastery` 表按知识点记录 score/attempts/correct/wrong，判卷 verdict
  （对/部分对/错）与反馈信号实时调整；每次调整追加 `mastery_history`，记忆图谱页画按日趋势线；
  知识点名称经相似度模糊匹配（避免 LLM 表述漂移）。
- **错题本**：判卷结果持久化用户作答，`GET /api/spaces/{sid}/wrong-questions` 跨测验聚合错题，
  支持整卷/勾选重做（`POST …/wrong-questions/redo`），重做答对自动推进复习间隔。
- **学习分析**：每累计 8 条新消息自动运行（meta 记录位置，不漏触发）：L2 摘要 → L3 提取 →
  对话级薄弱/进步点提取更新掌握度。
- **复习调度**：`GET /api/spaces/{sid}/review/due` 查看到期知识点；技能 `review.generate`
  针对到期/最薄弱知识点出复习题，答对自动推进复习间隔；左栏「记忆图谱」显示到期徽标，
  应用内顶部横幅 + 系统通知（需授权）每 5 分钟提醒一次。
- **新技能**：`exam.mock`（模拟考试，限时由前端倒计时）、`flashcard.generate`（闪卡）、
  `teach.check`（费曼讲解检验）、`wrong.redo`（错题重做）、`wrong.variants`（错题变式：
  同知识点换数字/换情境/换问法出 1 道新题，防背答案）。

## 闪卡与学习计划

- **闪卡（FSRS 调度）**：`flashcards` 表带 FSRS 状态（state/step/stability/difficulty/last_review +
  reps/lapses 计数），封装在 `app/fsrs.py`（[py-fsrs](https://github.com/open-spaced-repetition/py-fsrs)，
  MIT）；刷卡自评四档「忘了/困难/良好/轻松」（旧「记得/忘了」布尔仍兼容，映射良好/忘了），
  目标留存率 0.9、单卡最长一年重现；到期查询 `GET /api/spaces/{sid}/flashcards?due=1`
  附带四档按钮的下次间隔预告。老 Leitner 数据零迁移：首次评分按旧盒位间隔折算初始稳定性后由
  FSRS 接管，`box` 列保留仅作展示。
- **知识点复习排期**：`mastery` 表同构 FSRS 列，BKT 只负责 P(已掌握)，复习间隔由 FSRS 按证据
  档位（correct→良好 / partial·progress→困难 / confused·wrong→忘了）调度，答错稳定性坍缩、
  很快重现。
- **学习计划**：`plan.study` 输出结构化阶段任务（内容/验收标准/涉及知识点/截止日期，
  今天日期注入 prompt 由模型按阶段推算）存 `plan_tasks` 表（`due_date` 列，老库自动迁移），
  前端打卡并计算进度；`POST /api/spaces/{sid}/plan/{tid}/date` 可改期；
  重新生成会整体替换当前计划。
- **今日学习**：`GET /api/spaces/{sid}/today` 聚合到期复习点（FSRS）、到期闪卡、
  今日/逾期/未排期计划任务与今日打卡数、错题数——学生每天打开就知道该学什么。

## 模型通道：本地 / 云端

- 左侧「模型设置」页（或 `GET/PUT /api/llm/config`）配置云端 OpenAI 兼容 API 与路由策略：
  `local` 全本地 / `auto` 重任务（出题/判卷/分析/规划/抽取）走云端 / `cloud` 全云端。

- 云端密钥仅存本机 `data/llm_config.json`（接口只回掩码）。

## 混合检索（向量 × BM25，RRF 融合）

答疑/出题的讲义检索是**双通道**（`rag.retrieve`，封装在 `app/rag.py`）：

- **向量通道**：BGE 语义检索，负责换说法的语义匹配；
- **BM25 词法通道**：中文按字+二元组、拉丁按整词（零依赖纯 Python 实现，索引按空间缓存），
  专有名词、公式符号、章节标题等"词面精确匹配"场景向量检索常漏召，由该通道补齐；
- **RRF 融合**：两通道排名倒数融合（k=60，每通道超采 3×），引用里的 score 为融合归一化
  相关度（Top1=1.0）；`HYBRID_SEARCH=0` 可退回纯向量模式；
- **可选精排**：配置 `RERANK_MODEL`（如 `BAAI/bge-reranker-v2-m3`）后对融合候选做
  cross-encoder 重排（首次使用自动下载，失败静默回退融合序），留空关闭。

## 防降智措施

- 上下文预算：`max_context_chars`（默认 12000）统一限制 prompt 长度，讲义片段按相关度
  截取，防止超模型上下文被截断；
- JSON 容错：出题/判卷/抽取全部走 `chat_json`，自动截取最外层 JSON、失败纠错重试一次；
- 生成参数：结构化任务 max_tokens 提至 1600–2600，避免长 JSON 被截断；
- 连接复用：httpx 连接池常驻（keep-alive 600s），本地/云端各自独立连接。

## 知识缺陷诊断引擎（BKT × 遗忘曲线 × 依赖传播）

记忆图谱页顶部的「知识缺陷诊断」面板，排序依据是**综合风险**而非单点得分：

- **贝叶斯知识追踪（BKT）**：每次测验/反馈证据都做贝叶斯后验更新 P(已掌握)——
  参数 P(学习转移)=0.13、P(失误)=0.10、P(蒙对) 按题型区分（选择/判断 0.25、简答 0.05），
  部分/混淆类证据按强度做软观测混合，不再是无依据的固定加减分；
- **遗忘曲线留存率**：优先按 FSRS 幂律遗忘曲线（R = (1 + 19/81·Δt/S)^-0.5，S 为该知识点
  的个人稳定性）估算"此刻还记得多少"，无 FSRS 状态的老数据退回复习盒半衰期公式
  （R = 0.5^(Δt/半衰期)），掌握但久未复习的知识点会浮上来；
- **前置依赖风险传播**：知识点依赖图（讲义 LLM 抽取 + 内置课程图谱）上做松弛传播，
  前置薄弱按 0.6 系数拖累后继的"有效掌握度"——高斯定理不会了，可能根因在场强叠加；
- **诊断输出**：综合风险排序、建议修复顺序（薄弱子图上依赖拓扑 + 有效掌握度升序，
  根因优先）、根因链（沿最薄弱前置回溯）、错因统计（概念误解/计算失误/记忆模糊/审题错误）、
  受累下游清单。

图谱构建：技能 `graph.build`（记忆图谱页按钮），LLM 从知识点与讲义抽边（带模糊映射纠漂移）
并与 `backend/app/curriculum/` 内置课程图谱（高数/线代/概率/普物/机械原理/控制工程，103 概念）
按名称模糊匹配合并；接口 `GET /api/spaces/{sid}/defects`、`GET /api/spaces/{sid}/graph`、
`GET /api/curriculum`。新课程图谱：仿照现有 JSON 在 `curriculum/` 增加文件即可。
记忆图谱页的「知识依赖图谱」卡片把该图渲染为力导向 SVG：节点按掌握状态着色
（红=薄弱/黄=学习中/绿=已掌握/灰=未测），实线边=讲义抽取、虚线边=内置图谱匹配，
箭头指向后继；点节点看前置/后继与掌握详情，并可一键「出 3 题练它」直达测验。

## 个人档案 · 成长手册 · 升学战略引擎

左侧「个人档案」页（单用户，信息只存本机）：一次性维护学生名片
（本科院校/专业/年级/排名/情况标签如"重修、跨考"/目标院校专业/时间线），并跨空间汇总
学习总览（各空间知识点掌握度、薄弱点、到期复习、测验与闪卡数）。

左侧「成长手册」页：表单自动带入已保存的个人档案（留空字段在服务端同样回填），
引擎按 **真实院校政策库 × 情况模板 × StudyPilot 掌握度数据** 生成分阶段成长手册（Markdown，可存档）。

- **政策情报库**（`backend/app/policy/`，5 份文档，每条事实带官方来源 URL）：
  教育部考研报考资格、示例大学学籍与推免细则（重修仅限一次/推免按正考成绩前 30%）、
  清华机械系 085500 招生与复试口径（拟招 13 人、面试权重 4.5 倍）、人大推免要求、竞赛与科研
  补强时间窗。生成时按档案语义检索注入，关键结论强制标注 `[政策N]` 来源，库里没有的写"需自行核实"。
- **情况模板**：重修逆袭（保研断绝判定→统考主攻+复试对冲）/ 保研冲刺 / 跨考补课 / 稳健统考，
  按档案标签自动匹配组合。
- 扩展新院校：仿照现有格式在 `policy/` 增加该校学籍+推免+招生的 MD 文档（注明来源与年份）即可，
  无需改代码。
- 接口：`POST /api/handbook/generate`、`GET /api/handbook`、`GET/DELETE /api/handbook/{id}`。
- 档案接口：`GET/PUT /api/profile`、跨空间总览 `GET /api/profile/overview`。

## 教材书库

像词库一样管理的教材库（左侧「教材书库」，全局生效、不绑定空间）：

- **预置书目**：按课程体系预置 59 本——官方免费开放教材（Hefferon 线代、Boyd 凸优化、
  Grinstead & Snell 概率论、Modern Robotics、Underactuated Robotics、SLP3、
  d2l 中文版、邱锡鹏《神经网络与深度学习》等，均带官方直链或来源页）+ 路线图书单
  （机械原理/机械设计/控制工程基础等仅收录书目信息，不含全文）。
- **一键获取**：`POST /api/library/{bid}/fetch` 从官方直链下载开放教材（仅 http/https 公网
  地址，拒绝内网/保留段；文件写入上传目录内受控路径）。
- **自有教材导入**：前端「上传教材文件 / 整个文件夹批量导入」，支持 PDF/TXT/Markdown/PPTX/
  图片/zip 压缩包。PPTX 用标准库解析幻灯片文本与讲者备注（解析前拒绝 DTD/实体声明并限制
  条目大小）；图片经 RapidOCR 离线 OCR 提取文字（模型随包分发，完全本地，最长边缩至 2000px
  控制耗时）；zip 经 `ingest.expand_zip` 安全展开（落盘名与包内成员名彻底解耦 + realpath
  包含校验防 Zip Slip、按实际字节计量防 zip 炸弹、跳过嵌套压缩包，单文件 300MB/总量 500MB/
  300 个文件上限），包内每个文件各成一册书目。老版二进制 .ppt 不支持，会提示另存为 .pptx
  或导出 PDF。受版权保护的教材请通过正版渠道获得后自行导入，服务端不抓取任何盗版资源。
- **网页剪藏**：`POST /api/library/url` 粘贴在线讲义/文章链接，服务端抽取正文存为 TXT 书目
  （复用与教材获取同一套 SSRF 防护：仅公网 http/https，拒绝内网/保留段，单页 5MB 上限）。
- **挂载到空间**：`POST /api/library/{bid}/attach` 把已入库教材接入某课程空间的 RAG，
  答疑/出题引用书内内容并标注来源；同一空间重复挂载幂等。

## MCP 扩展

`POST /api/connectors/mcp {"name":"fs","command":["npx","-y","@modelcontextprotocol/server-filesystem","C:/path"]}`
注册后持久化保存（meta 表，重启自动恢复），可在「模型设置」页可视化管理（注册/删除）。

答疑时 Ask 专家具备工具循环：`experts._chat_with_tools` 把所有已注册 server 的工具清单注入
system，模型可用 `{"tool_call":{...}}` 请求调用（最多 3 轮往返），工具结果回填后继续作答——
例如挂载 filesystem server 即可在答疑中读取本地课件原文。
